# Задачи для версии 0.3 (v0.3 Roadmap)

## Задача 1: Устранение покадровых скачков и ультра-плавный скраббинг (Frame Smoothing & Transition) [DONE]

### Проблема:
При прокрутке страницы в секциях `HeroVideoSection` и `TechniqueVideoSection` местами ощущается дискретность, ступенчатость и микро-скачки («покадровость») при смене кадров.

### Что сделано:
1. **Субкадровый альфа-блендинг (Cross-fade)**:
   - Внедрена интерполяция между $f_0$ и $f_1$ (`ctx.globalAlpha = alpha`), полностью устраняющая дискретность и ступенчатость движения между кадрами.
2. **Устранение фликеринга и монотонная стабилизация**:
   - В алгоритме `findBestFrame` добавлено удержание текущего кадра при малых дельтах, исключающее «пинг-понг» и мерцание при фоновой загрузке.
3. **Динамическое окно приоритета воспроизведения (`prioritizeWindow`)**:
   - При скролле кадры в окне текущей позиции немедленно поднимаются в начало очереди загрузки.
4. **Асинхронный декодинг (`img.decode()`)**:
   - Декодирование WebP вынесено за пределы главного потока, устранены микро-фризы при первом вызове `drawImage`.
5. **Тюнинг LERP**:
   - Коэффициент сглаживания скорректирован до `0.28`, устранен 300мс лаг задержки относительно Lenis.

## Задача 2: Мобильная адаптация и центрирование Canvas-видеоряда (Mobile Viewport Scaling)

### Проблема:
На мобильных экранах (вертикальная ориентация 9:16 / 19.5:9) горизонтальные кадры видеоряда требуют аккуратного масштабирования и центрирования, чтобы главный объект композиции всегда оставался в фокусе и не искажался.

### Что необходимо сделать:
1. **Масштабирование и центрирование (Aspect Ratio & Focal Alignment)**:
   - Настроить логику `draw` в `src/lib/frame-scrub.ts` с поддержкой адаптивного фокуса (focal point / center crop) для мобильных пропорций.
   - Обеспечить полное заполнение по высоте (`full-height / cover`) без визуального растяжения и деформаций на экранах разной ширины (от 360px до 430px+).
2. **Мобильная производительность и учет динамического Viewport**:
   - Корректная обработка изменения высоты экрана при скрытии/появлении адресной строки браузера (dynamic viewport `100dvh / window.innerHeight`).
   - Контроль потребления памяти и ограничение `devicePixelRatio` на мобильных устройствах для сохранения стабильных 60 FPS.

### Статус реализации:
- [x] Реализован расчет cover-масштабирования от родительского контейнера без учета GSAP CSS-трансформов.
- [x] Округление координат и размеров отрисовки (`Math.ceil` / `Math.round`) для исключения субпиксельных гэпов.
- [x] Секции переведены на адаптивный dynamic viewport `h-screen min-h-[100dvh]`.
- [x] `ScrollTrigger.config({ ignoreMobileResize: true })` для исключения скачков пиннинга при скрытии адресной строки браузера.
- [x] `ResizeObserver` переведен на родительский контейнер для исключения циклов перерисовки при анимации масштаба.
